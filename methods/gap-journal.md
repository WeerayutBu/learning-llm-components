# Gap journal

Recurring stuck points, guesses, Step-4 diffs, and bug taxonomy — the raw material for
what to drill next. Reviewed weekly. One entry per gap, tagged with its mechanism.

## Entry template

```
### <date> · <mechanism> · <short title>
- Where it bit: Step-1 blind / Step-4 diff / debugging
- What I got wrong:
- Why: the underlying misconception
- Fix / rule to remember:
- Drill?: yes/no — what to re-run blind
```

## Bug taxonomy
